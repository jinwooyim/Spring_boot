## 🔍 소개

이 프로젝트는 Spring Boot 기반의 웹 애플리케이션입니다.  
사용자 인증, CRUD 기능, 파일 업로드, API 연동 등 백엔드의 전형적인 기능을 구현하며, 확장 가능성과 유지보수성을 고려하여 설계되었습니다.

---

## 🚀 기능 요약

- ✅ 사용자 회원가입 및 로그인 (JWT 기반 인증)
- ✅ 게시판 CRUD (글쓰기, 수정, 삭제, 댓글)
- ✅ 파일 업로드/다운로드 기능
- ✅ RESTful API 설계
- ✅ 페이지네이션 및 검색 기능
